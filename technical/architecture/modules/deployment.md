# Architecture — Deployment

Deployment flexibility: cloud, customer-controlled infrastructure, and private deployments.

## Options

- **Managed cloud platform** — primary offering, operated by Eclipse
- **Customer-controlled infrastructure** — Docker Compose on customer's machines, self-hosted from day one
- **Private deployments** — for customers requiring full control over data and infrastructure
