# Architecture — Agent Studio (Deferred)

Visual builder and SDK for agent creation.

**Status: Deferred / post-MVP.** Eclipse governs agents; it does not need to be the place where they are visually built. The Agent Studio is intentionally out of MVP because Google AI Studio and Claude already provide visual agent building within their platforms. Eclipse's differentiator is independent cross-provider governance, not agent creation.

Revisit only if customers demonstrate demand for a visual builder.

- **Visual**: users configure agent instructions, model, tools, knowledge and workflow
- **Developer**: SDK and APIs to create, configure and deploy agents
