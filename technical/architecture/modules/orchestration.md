# Architecture — Orchestration (Deferred)

Coordinates agent tasks, workflows, tool calls, handoffs and retries.

**Status: Deferred / post-MVP.** Customers already use n8n, LangGraph, CrewAI, and similar orchestration engines. Eclipse does not need to own orchestration — it governs the agents that orchestration engines invoke.

Initially integrate an established engine such as LangGraph or n8n rather than building your own.
