# Product — Agent OS Control Center

Agent OS offers one primary experience for the MVP:

## Experience — Agent OS Control Center

Manage agent identities, permissions, approvals, monitoring, costs, and security across every supported agent framework.

- Agent identity and scoped permissions (multi-provider)
- Approval queue and approval history (bound to exact action + parameters)
- Monitoring: work completed, pending approvals, failed tasks, security incidents, agent costs
- Audit log with verification (hash-chained, tamper-evident)
- Integration SDK documentation and agent onboarding

## Who this serves

- **CTO, IT director, cybersecurity manager** who needs central control over agents from multiple providers
- **Developers** who need SDK + APIs to connect existing agents to Eclipse

## What is deferred

**Agent OS Studio** (visual builder for agent instructions, model, tools, knowledge, workflow) is intentionally out of MVP. Eclipse governs agents; it does not need to be the place where they are visually built. Revisit only if customers demonstrate demand.
