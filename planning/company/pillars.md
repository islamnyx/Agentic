# Company — Strategic Pillars

| Pillar | Strategic objective |
|--------|---------------------|
| Agent Registry | Discover and register agents from any supported framework (Gemini, Claude, OpenAI, n8n, custom, MCP) |
| Agent Identity & Access | Give every registered agent a distinct identity, credentials, and scoped permissions |
| Secure Execution Gateway | Intercept, allow, deny, or request approval for tool calls to protected business systems |
| Unified Audit & Monitoring | One tamper-evident audit trail for agent activity across all providers |
| Integration SDK | Simple way for developers to connect their existing agents to Eclipse |
| Security | Enforce identity, permissions, policies, approvals, secrets, immutable audit |
| Company Brain | Shared knowledge layer with per-item access permissions |
| Departments & Teams | Organize agents into departments governed by the Eclipse Security Layer |
| Approvals Platform | Reusable human-in-the-loop approval bound to exact action and parameters |
| Deployment flexibility | Cloud, customer-controlled infrastructure, and private deployments |

## Design Principle

Eclipse does not need to own the underlying AI model or agent framework. It governs how agents interact with the business. Security is the core differentiator: identity, permissions, policy evaluation before sensitive actions, human approval, secrets management, immutable audit records, emergency agent revocation — all enforced outside the language model.
